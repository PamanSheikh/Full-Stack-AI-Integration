# 🚀 Full Stack AI Integration Project (React + FastAPI + Gemini API)

This is a full-stack AI web application that integrates:
- React (Frontend)
- FastAPI (Backend)
- Google Gemini API (AI model)
- Environment-based secure API key management

Users can send prompts from the frontend and receive AI-generated responses from Gemini in real time.

---

## ⚙️ Features

- AI-powered response generation using Gemini API
- Secure API key storage using `.env`
- FastAPI backend for handling requests
- React frontend for user interaction
- Real-time prompt → response system
- Clean full-stack architecture
